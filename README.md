## О проекте

Приложение на Python для **сравнения алгоритмов нахождения хроматического числа обыкновенного графа** с акцентом на их точность и скорость работы. В проекте реализованы три алгоритма разных классов:

- **метод Магу** — точный алгоритм на основе булевой алгебры, в том числе с параллельным раскрытием выражений;
- **жадный алгоритм** — быстрая эвристика;
- **генетический алгоритм** — метаэвристика с настраиваемыми параметрами.

Для них есть графический интерфейс: генерация случайных графов, раскраска и визуализация результата, серийные эксперименты и сравнительные диаграммы по времени и точности.

### Актуальность

Задача раскраски графа относится к классу NP-трудных задач. Она лежит в основе практических задач оптимизации вычислительных ресурсов:

- распределение частот и вышек сотовой связи;
- распределение регистров в микропроцессорах;
- составление расписаний.

## Теория кратко

**Правильная раскраска** графа $G$ — это присвоение каждой вершине цвета из $\{1, \dots, k\}$ так, чтобы для любых смежных вершин $u$ и $v$ выполнялось $c(u) \ne c(v)$.

**Хроматическое число** $\chi(G)$ — наименьшее $k$, для которого существует правильная раскраска:

$$\chi(G) = \min \{\, k \mid \exists \text{ правильная раскраска } c : V \to \{1, 2, \dots, k\} \,\}$$

Подходы к решению:

- **точные алгоритмы** (метод ветвей и границ, метод Магу) гарантируют оптимальный результат, но требуют экспоненциального времени на плотных графах;
- **эвристики** (жадная раскраска, DSATUR) работают за полиномиальное время, но не гарантируют минимальность числа цветов;
- **метаэвристики** (генетические алгоритмы, имитация отжига) ищут компромисс между точностью и скоростью.

## Реализованные алгоритмы

| Алгоритм | Класс | Идея | Результат |
| -------- | ----- | ---- | --------- |
| Метод Магу | точный | Раскрытие булева выражения, поиск независимых множеств и покрытие ими всех вершин | Точное $\chi(G)$ |
| Жадный | эвристика | Вершины по убыванию степени, каждой назначается минимальный цвет, не занятый соседями | Приближение $\chi(G)$ сверху |
| Генетический | метаэвристика | Эволюция популяции раскрасок | Приближение $\chi(G)$ |

### Метод Магу

Точный метод, использующий булеву алгебру. Хроматическое число равно минимальному числу независимых множеств, покрывающих все вершины графа.

Метод имеет экспоненциальную сложность порядка $O(2^m)$, где $m$ — число рёбер, из-за раскрытия ДНФ:

$$DNF = \prod_{i=1}^{m} (x_{u_i} + x_{v_i})$$

#### Пример

Для графа из 4 вершин с рёбрами 1–2, 1–3, 2–3, 2–4, 3–4:

1. $(x_1 + x_2)(x_1 + x_3)(x_2 + x_3)(x_2 + x_4)(x_3 + x_4)$
2. после раскрытия: $x_1x_2x_3x_4 + x_1x_2x_3 + x_1x_2x_4 + x_1x_3x_4 + x_2x_3x_4 + x_2x_3$
3. независимые множества (дополнения конъюнкций): $\{x_1x_4\},\ \{x_4\},\ \{x_3\},\ \{x_2\},\ \{x_1\}$
4. раскраска: «красный» — вершины $x_1, x_4$; «синий» — $x_3$; «зелёный» — $x_2$. Значит, $\chi(G) = 3$.

### Параллельная реализация метода Магу

Самая затратная часть метода — раскрытие скобок. Параллельная версия разбивает произведение на подвыражения (по нескольку скобок), раскрывает их одновременно, затем перемножает результаты:

$$final\_result = \prod_{i=1}^{k} expanded\_expression_i$$

где $k$ — число подвыражений. Функция `parallel_expand` распределяет подвыражения между рабочими потоками, а `expand_expression` выполняет символьное раскрытие средствами SymEngine.

- `main_parallel.py` — эксперимент по сравнению параллельного (`ThreadPool`, 4 потока) и последовательного раскрытия ДНФ;
- `main.py` — полная реализация метода (`Graph.method_MAGU`), в которой раскрытие распараллелено через `multiprocessing.Pool`.

### Жадный алгоритм

1. Упорядочить вершины по убыванию степени.
2. Для каждой вершины назначить минимальный цвет, не используемый её соседями.
3. Повторить для всех вершин. Число цветов равно максимальному номеру цвета плюс один.

### Генетический алгоритм

Особь — массив, где индекс соответствует вершине графа, а значение — присвоенному ей цвету.

- **Начальная популяция** создаётся одним из методов: жадным, случайным безопасным, DSATUR или на основе независимых множеств.
- **Приспособленность:** $-(\text{конфликты}) - (\text{число цветов})$, то есть штраф за соседние вершины одного цвета и за каждый использованный цвет.
- **Элитизм:** 10 % лучших особей переходят в следующее поколение без изменений.
- **Селекция:** турнирная (из двух случайных особей выбирается лучшая).
- **Кроссовер:** одноточечный, применяется с заданной вероятностью.
- **Мутация:** случайная вершина перекрашивается в неконфликтный существующий цвет или в новый, с заданной вероятностью.
- **Остановка:** либо по заданному числу поколений, либо когда найденное хроматическое число не улучшается заданное число повторов.

## Как работает программа

1. Пользователь задаёт параметры генерируемого графа, данные проверяются.
2. Выбирается конфигурация: один алгоритм, несколько алгоритмов или анализ сохранённых результатов.
3. Граф создаётся: каждая пара вершин соединяется ребром с заданной вероятностью либо случайно выбирается ровно $m$ рёбер из всех возможных. Если $m > n(n-1)/2$, возвращается ошибка.
4. Выполняются выбранные алгоритмы, определяются хроматическое число и раскраска.
5. Отображаются граф с раскраской, хроматическое число, число рёбер и время выполнения.

Результат каждого запуска дописывается в файл `test_all_methods.txt` в формате `{'method': ..., 'time': ..., 'nodes': ..., 'edges': ..., 'result': ...}`. После серии из нескольких графов файл автоматически переименовывается в `test1.txt`, `test2.txt` и так далее — его можно открыть на вкладке «Анализ».

### Параметры в интерфейсе

| Параметр | Описание |
| -------- | -------- |
| Количество вершин, количество графов | Размер графа и число графов в серии |
| Вероятность рёбер / количество рёбер | Переключается флажком «Случайные рёбра» |
| Алгоритмы | Жадный, Генетический, Магу (можно выбрать несколько) |
| Кол-во особей, вер. мутации, вер. кроссовера | Параметры генетического алгоритма |
| Нач. популяция | Жадный, Случайный, DSATUR, Нез. множ. |
| Кол-во повторов / поколений | Условие остановки генетического алгоритма |
| Метрика (вкладка «Анализ») | Время или точность |

### Выводы

- **Метод Магу** точный, но очень медленный: время растёт экспоненциально с размером графа.
- **Жадный алгоритм** практически мгновенный, но даёт наименее точный результат.
- **Генетический алгоритм** — оптимальный баланс: результат близок к точному при времени работы в доли секунды.
- Параллельное раскрытие ДНФ ускоряет метод Магу примерно вдвое.

## Установка и запуск

1. Установите [Python 3](https://www.python.org/downloads/) (модуль `tkinter` входит в стандартную поставку).
2. Установите зависимости:

   ```bash
   pip install numpy networkx matplotlib symengine ttkthemes
   ```

3. Клонируйте репозиторий и запустите приложение из его корневой папки:

   ```bash
   git clone https://github.com/DenkiGO/Chromotic-Number-Of-Graph.git
   cd Chromotic-Number-Of-Graph
   python interface.py
   ```

Эксперимент по сравнению параллельного и последовательного метода Магу запускается командой `python main_parallel.py`.
